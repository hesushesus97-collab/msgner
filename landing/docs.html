Vibe / Документация Python SDK

1. Быстрый старт: Создание первого бота

Библиотека vibebots позволяет разрабатывать высокопроизводительных ботов на Python с поддержкой интерактивных инлайн-кнопок, кастомных цветов и мгновенных ответов.

Python (bot.py)
from main import Bot

# 1. Инициализируем бота с уникальным токеном
bot = Bot(token="YOUR_BOT_TOKEN_HERE")

# 2. Регистрируем обработчик команды /start
@bot.message_handler(commands=['start'])
def send_welcome(message):
    bot.send_message(
        user_id=message.sender_id,
        text=f"Привет, {message.sender_info.name}! Добро пожаловать в Vibe."
    )

# 3. Запускаем опрос обновлений
if __name__ == '__main__':
    print("Бот Vibe успешно запущен...")
    bot.start_polling()

2. Polling & Обработка обновлений

Метод bot.start_polling() автоматически получает входящие события (сообщения и нажатия на кнопки) и передает их в соответствующие обработчики.

Python
# Параметр skip_updates=True пропускает сообщения, отправленные во время оффлайна бота
bot.start_polling(skip_updates=True)

3. Обработка сообщений и фильтры

Декоратор @bot.message_handler() позволяет перехватывать входящие сообщения с использованием различных фильтров.

Фильтрация по командам и тексту

Python
# Обработка списка команд
@bot.message_handler(commands=['help', 'about', 'info'])
def handle_info(message):
    bot.send_message(message.sender_id, "Я официальный бот на платформе Vibe Messenger.")

# Фильтрация по содержимому с помощью lambda
@bot.message_handler(func=lambda msg: "заказ" in msg.content.lower())
def handle_order(message):
    bot.send_message(message.sender_id, "Оформление заказа началось. Напишите ваш город:")

Отправка действий в чате (Typing Indicator)

Вы можете показать пользователю, что бот печатает ответ, перед длительной операцией:

Python
# Показывает "печатает..." в строке статуса
bot.send_chat_action(user_id=message.sender_id, action="typing")

4. Инлайн-кнопки, Сетка 5x10 и Кастомные цвета

Vibe Messenger предоставляет богатейшие возможности кастомизации кнопок:

  • Сетка: до 5 кнопок в одном ряду и до 10 рядов суммарно (до 50 кнопок).
  • Кастомный фон (bg_color): любой HEX цвет (например, #6366F1, #EF4444, #10B981).
  • Кастомный текст (text_color): контрастный цвет текста на кнопке.
  • Эффект стекла (Glassmorphism): полупрозрачный градиент, тонкая граница и зеркальный блик по умолчанию.
Python
from main import InlineKeyboardMarkup, InlineKeyboardButton

def create_control_panel():
    # Создаем клавиатуру с сеткой по 2 кнопки в ряд
    kb = InlineKeyboardMarkup(row_width=2)

    # 1. Кнопка с фиолетовым фоном
    btn_start = InlineKeyboardButton(
        text="🚀 Запустить",
        callback_data="cmd_start",
        bg_color="#8B5CF6",
        text_color="#FFFFFF"
    )

    # 2. Кнопка с красным фоном (Danger)
    btn_stop = InlineKeyboardButton(
        text="🛑 Остановить",
        callback_data="cmd_stop",
        bg_color="#EF4444",
        text_color="#FFFFFF"
    )

    # 3. Кнопка с изумрудным фоном (Success)
    btn_status = InlineKeyboardButton(
        text="📊 Статистика",
        callback_data="cmd_status",
        bg_color="#10B981",
        text_color="#FFFFFF"
    )

    # 4. URL-кнопка для перехода на документацию
    btn_link = InlineKeyboardButton(
        text="🌐 Веб-портал",
        url="https://example.com"
    )

    # Добавляем кнопки парами в сетку
    kb.add(btn_start, btn_stop, btn_status)
    
    # Метод .row() добавляет кнопку на всю отдельную строку
    kb.row(btn_link)

    return kb

@bot.message_handler(commands=['panel'])
def send_panel(message):
    bot.send_message(
        user_id=message.sender_id,
        text="🎛 Панель управления ботом:",
        reply_markup=create_control_panel()
    )

5. Обработка нажатий и ответы (Callbacks)

Когда пользователь нажимает на инлайн-кнопку, сервер Vibe передает событие callback_query в ваш бот. Бот может моментально ответить всплывающим тостом или модальным диалогом через метод call.answer().

Всплывающий тост vs Модальное окно (Alert)

Python
@bot.callback_query_handler()
def handle_all_clicks(call):
    print(f"Пользователь {call.sender_id} нажал: {call.data} на сообщении {call.message_id}")

    if call.data == "cmd_start":
        # 1. Тост внизу экрана (show_alert=False)
        call.answer("Сервер успешно запущен!", show_alert=False)
        bot.send_message(call.sender_id, "✅ Процесс запущен в фоновом режиме.")

    elif call.data == "cmd_stop":
        # 2. Модальный диалог с кнопкой OK (show_alert=True)
        call.answer(
            text="⚠️ Внимание! Все несохраненные данные будут сброшены.",
            show_alert=True
        )

    elif call.data == "cmd_status":
        call.answer("Память: 42% | ЦПУ: 12% | Uptime: 99.9%", show_alert=False)

6. Защита от спама (3 клика в секунду)

На уровне WebSocket шлюза Vibe реализован автоматический Rate Limiter по скользящему окну времени (Sliding Window): максимум 3 клика в 1.0 секунду от одного пользователя.

Защита инфраструктуры:

Если пользователь попытается спамить кнопку кликером, сервер автоматически отклонит лишние запросы и покажет предупреждение пользователю, не создавая нагрузку на ваш процесс бота.

7.5. Новые методы: редактирование, реакции, закрепления и команды

Начиная с этой версии библиотека умеет не только отправлять сообщения, но и редактировать их, удалять, пересылать, ставить реакции, закреплять сообщения, читать историю переписки и удобно роутить команды. Все действия отображаются в мессенджере в реальном времени.

Объект Message и его методы-ярлыки

Каждый обработчик сообщений получает объект Message — это обычный словарь (message.content, message.sender_id работают как раньше) с удобными свойствами и методами.

Свойство / Метод Тип Описание
message.text str Текст сообщения (алиас content).
message.user_id int ID отправителя (алиас sender_id).
message.message_id int Реальный ID сообщения (для edit/delete/react).
message.command Optional[str] Имя команды без слэша, либо None.
message.args List[str] Аргументы команды списком.
message.args_text str Всё после команды одной строкой.
message.reply(text, quote=False) method Ответить отправителю (можно цитатой).
message.edit(text) method Отредактировать это сообщение (для сообщений бота).
message.delete() method Удалить это сообщение (для сообщений бота).
message.react(emoji) method Поставить реакцию на сообщение.
message.pin() method Закрепить сообщение.
message.forward_to(user_id) method Переслать сообщение пользователю.

Роутинг команд: @bot.command(...) и command=

Регистрируйте команды одним из способов: коротким декоратором @bot.command("start") или через @bot.message_handler(command=...) / commands=[...].

python
from main import Bot, InlineKeyboardMarkup, InlineKeyboardButton

bot = Bot("YOUR_BOT_TOKEN")

# Короткий декоратор команды
@bot.command("start")
def start(message):
    message.reply(f"Привет, {message.sender_info.name}! Я на связи.")

# Несколько команд сразу + аргументы
@bot.message_handler(commands=["say", "echo"])
def say(message):
    if message.args:
        message.reply("Вы сказали: " + message.args_text)
    else:
        message.reply("Использование: /say текст")

# Обычный текст (без команды)
@bot.message_handler()
def fallback(message):
    message.reply("Не понял команду. Напишите /start")

bot.start_polling()

Редактирование и удаление сообщений

python
@bot.command("counter")
def counter(message):
    kb = InlineKeyboardMarkup().row(
        InlineKeyboardButton("➕", callback_data="inc"),
    )
    bot.send_message(message.user_id, "Счётчик: 0", reply_markup=kb)

@bot.callback_query_handler(data="inc")
def on_inc(call):
    # Редактируем то самое сообщение, где кнопка
    call.edit_message("Счётчик обновлён!", reply_markup=InlineKeyboardMarkup().row(
        InlineKeyboardButton("➕", callback_data="inc")
    ))

@bot.command("selfdestruct")
def selfdestruct(message):
    sent = message.reply("Это сообщение самоуничтожится...")
    # sent.message_id — реальный ID отправленного сообщения
    bot.delete_message(sent.message_id)

Один токен — один экземпляр бота

По одному токену одновременно может работать только один экземпляр бота. Если запустить второй, первый автоматически получит ConflictError и корректно остановится (поведение управляется параметром stop_on_conflict в start_polling). Отдельные файлы блокировок больше не создаются — синхронизация ведётся через базу данных.

python
from main import Bot, ConflictError

# Через контекстный менеджер сессия закрывается автоматически (без утечек)
with Bot("YOUR_BOT_TOKEN") as bot:
    @bot.command("ping")
    def ping(message):
        message.reply("pong")

    bot.start_polling(stop_on_conflict=True)

8. Полные примеры ботов

Пример 1: Бот-Каталог товаров с корзиной

Python (store_bot.py)
from main import Bot, InlineKeyboardMarkup, InlineKeyboardButton

bot = Bot(token="YOUR_TOKEN")

PRODUCTS = {
    "phone": {"name": "Смартфон Vibe Pro", "price": "49 990 ₽", "color": "#6366F1"},
    "headphones": {"name": "Наушники GlassSound", "price": "12 490 ₽", "color": "#10B981"},
    "watch": {"name": "Умные часы V-Watch", "price": "18 990 ₽", "color": "#F59E0B"}
}

user_carts = {}

def get_store_keyboard():
    kb = InlineKeyboardMarkup(row_width=1)
    for code, item in PRODUCTS.items():
        btn = InlineKeyboardButton(
            text=f"{item['name']} — {item['price']}",
            callback_data=f"buy_{code}",
            bg_color=item["color"],
            text_color="#FFFFFF"
        )
        kb.add(btn)
    kb.row(InlineKeyboardButton("🛒 Моя корзина", callback_data="view_cart", bg_color="#3B82F6", text_color="#FFF"))
    return kb

@bot.message_handler(commands=['start', 'store'])
def open_store(msg):
    bot.send_message(msg.sender_id, "🏪 Добро пожаловать в фирменный магазин Vibe! Выберите товар:", reply_markup=get_store_keyboard())

@bot.callback_query_handler()
def handle_store_clicks(call):
    uid = call.sender_id
    data = call.data

    if data.startswith("buy_"):
        code = data.replace("buy_", "")
        item = PRODUCTS.get(code)
        if item:
            user_carts.setdefault(uid, []).append(item['name'])
            call.answer(f"✅ Добавлено: {item['name']}!", show_alert=False)
            
    elif data == "view_cart":
        cart = user_carts.get(uid, [])
        if not cart:
            call.answer("Ваша корзина пуста!", show_alert=True)
        else:
            items_str = "\n• " + "\n• ".join(cart)
            call.answer(f"В корзине {len(cart)} тов.:{items_str}", show_alert=True)

if __name__ == '__main__':
    bot.start_polling()

from main import Bot, InlineKeyboardMarkup, InlineKeyboardButton

bot = Bot(token="YOUR_TOKEN")

def on_quiz_answer(call):
