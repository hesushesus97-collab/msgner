Vibe Bot Platform

Создавайте ботов нового поколения

Наша Python-библиотека vibebots предоставляет простой и мощный инструментарий для взаимодействия с пользователями: команды, inline-клавиатуры с индивидуальными цветами и моментальная обработка нажатий в реальном времени.

Открыть документацию SDK
bot.py 
from main import Bot, InlineKeyboardMarkup, InlineKeyboardButton

bot = Bot(token="YOUR_BOT_TOKEN")

@bot.message_handler(commands=['start'])
def send_welcome(msg):
    kb = InlineKeyboardMarkup(row_width=2)
    btn1 = InlineKeyboardButton("🔥 Огонь", callback_data="fire", bg_color="#EF4444")
    btn2 = InlineKeyboardButton("✨ Магия", callback_data="magic", bg_color="#8B5CF6")
    kb.add(btn1, btn2)
    bot.send_message(msg.sender_id, "Привет! Выберите опцию:", reply_markup=kb)

@bot.callback_query_handler()
def on_click(call):
    call.answer(f"Вы выбрали: {call.data}", show_alert=True)

bot.start_polling()
